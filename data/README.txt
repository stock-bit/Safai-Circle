Rewari Sweeper Beat Planning System - Data Directory
=====================================================

Place your source files here for local quick-loading:

1. wards.kmz       - Ward Boundaries (32 Wards of Rewari Municipal Council)
2. ulb_roads.kml   - Municipal Council Rewari Road Network (Primary Dataset)
3. existing_roads.kml - Existing / Reference Haryana Roads (Secondary Dataset)

Note: You can also drag-and-drop or select any KML/KMZ files directly using the File Upload interface in index.html.
